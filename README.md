# Insurance Claims AI Assistant using RAG + AI Agents

## Project Overview
This project implements a Retrieval-Augmented Generation (RAG) solution using an Insurance Claims dataset. It demonstrates how Gen AI can be used as a serving layer on top of business-ready data.

## Technologies Used
- Python
- Streamlit
- FAISS
- Sentence Transformers
- Google Gemini
- LangChain
- Pandas

## Project Flow
Gold Dataset → Embeddings → FAISS Vector Store → RAG Retrieval → Gemini LLM → Streamlit Chatbot

## Features
- Natural language query support
- Semantic search using FAISS
- AI-generated responses
- Interactive Streamlit interface
